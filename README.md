# time-checker

Консольная утилита на Node.js + TypeScript для измерения скорости скачивания ресурса: скрипт 10 раз скачивает указанный URL, показывает текущую скорость в МБ/с и выводит среднее время скачивания и общий объём загруженных данных.

## Требования

- Node.js 18 или новее (используется встроенный `fetch`).

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

После запуска введите ссылку на ресурс, когда появится запрос:

```
Введите ссылку на ресурс: https://example.com/big-file.zip
```

## Как это работает

1. Скрипт запрашивает URL и последовательно скачивает его 10 раз.
2. Во время каждого скачивания в консоль выводится текущая средняя скорость в МБ/с, а также прогресс в процентах (если сервер отдаёт заголовок `Content-Length`).
3. По итогам 10 скачиваний выводится:
   - среднее время скачивания (в секундах);
   - общее количество скачанных данных (в мегабайтах).

Пример вывода:

```
12.35 МБ/с (45.2%)
...
Среднее время скачивания: 8.3 с
Общее кол-во скачанных данных: 104.5 мб
```

## Единицы измерения

| Величина | Единица | Как считается |
| --- | --- | --- |
| Скорость скачивания | МБ/с (мегабайт в секунду) | байты / 1000 / 1000 / секунды |
| Прогресс скачивания | % (один знак после запятой) | скачано / `Content-Length` × 100 |
| Время скачивания | миллисекунды внутри, секунды в выводе | `performance.now()`, в итоге делится на 1000 |
| Объём данных | байты внутри, МБ (мегабайты) в выводе | сумма `Content-Length`, в итоге делится на 1000 × 1000 |

Все величины приводятся к десятичным мегабайтам (1 МБ = 1 000 000 байт) — и скорость, и итоговый объём считаются одинаково.

## Примечания

- Если сервер не возвращает заголовок `Content-Length`, прогресс в процентах не отображается.
- При ошибке загрузки (неуспешный HTTP-статус или пустое тело ответа) скрипт завершится с ошибкой вида `Ошибка загрузки: <код>`.
